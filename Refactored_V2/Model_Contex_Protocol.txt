# OpenFAST Workflow Manager – Documentation Overview

## Project Structure

```
openfast_workflow/
├── main.py
├── gui.py
├── processing/
│   ├── __init__.py
│   ├── converters.py
│   ├── plotting.py
│   ├── frequency.py
│   └── dalembert.py
└── utils/
    ├── __init__.py
    └── file_utils.py
```

- `main.py` – Entry point; launches the Tkinter GUI.
- `gui.py` – Tkinter application that orchestrates case generation, simulation runs, and post-processing.
- `processing/` – Headless processing back-end (CSV conversion, plotting, frequency analysis, d’Alembert staticization).
- `utils/` – Shared helpers (currently file parsing utilities).

### `processing/converters.py`

#### Class `ConverterRunner`

Instantiate with a message queue (or any object with `.put(tuple)`), case name, and log type string used by the GUI.

| Method | Purpose / Usage Instructions |
| --- | --- |
| `__init__(self, message_queue, case_name, log_type)` | Set up logger context. |
| `log(self, message)` | Places a formatted tuple `(log_type, "[case][CSV] message")` on message queue. Use if you need custom logging before/after conversion. |
| `convert_openfast_to_csv_robust(self, input_file, output_file)` | Streams an OpenFAST `.out` text file to CSV, handling duplicate column headers and numerical formatting. Returns `True` on success. Typical usage: `converter = ConverterRunner(mq, "Case01", "post_proc_log"); converter.convert_openfast_to_csv_robust("case.out", "case.csv")`. |

## Usage Summary

1. **Launch GUI**: `python main.py` → interactively generate cases, run simulations, and post-process.
2. **Use processing modules headlessly**:
   ```python
   from processing import ConverterRunner, PlottingRunner, FrequencyAnalysisRunner, DalembertRunner

   mq = queue.Queue()  # or any object with .put()

   # CSV conversion
   ConverterRunner(mq, "Case01", "log").convert_openfast_to_csv_robust("input.out", "output.csv")

   # Plotting
   PlottingRunner(mq, "Case01", "log").run("output.csv", "plots_dir")

   # Frequency analysis
   FrequencyAnalysisRunner(mq, "Case01", "log").run("output.csv", "PtfmHeave", "freq_dir", 300.0)

   # d'Alembert analysis
   DalembertRunner(mq, "Case01", "log").run(
       fst="Case01.fst",
       glue_out="Case01.out",
       outdir="dalembert_dir",
       analysis_start_time=300.0,
   )
   ```

3. **Utilities** (`utils.file_utils`) support discovery and parsing tasks; import as needed.

This documentation captures the full project structure and provides usage guidance for every defined method/function in the repository.
